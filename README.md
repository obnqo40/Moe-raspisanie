# Моё Расписание - Электронный помощник

## Описание
Это веб-приложение для управления школьным расписанием. Поддерживает роли ученика и учителя, автогенерацию расписания, экспорт в Excel и PWA (установку на телефон/ПК).

## Функционал
- **Авторизация/Регистрация**: Роли "Ученик" и "Учитель".
- **Расписание**: Просмотр, добавление, редактирование, удаление уроков.
- **Генератор**: Автоматическое создание расписания на основе учебного плана.
- **Экспорт/Импорт**: Excel (.xlsx).
- **PWA**: Работает офлайн (после первой загрузки).

## Запуск
1. Просто откройте `index.html` в браузере.
2. Для работы PWA и некоторых функций может потребоваться локальный сервер (например, Live Server в VS Code) или HTTPS.

## Настройка GitHub (для синхронизации)
В профиле учителя можно настроить синхронизацию с GitHub репозиторием для хранения `users.json` и `schedule.json`.
1. Создайте репозиторий.
3. Введите Owner, Repo, Branch и Token в настройках профиля.
